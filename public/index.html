服务条款

创建账号

注册后即可申请根域名下的二级子域名

仅支持 Gmail / QQ 邮箱
无需邮箱验证，注册后直接登录。
同一网络最多注册 2 个账号，超限账号一经发现将被全部封禁。

账户控制台

登录后可在控制台查看你名下的全部子域名，管理 A、AAAA、CNAME、MX、TXT、NS、SRV、CAA、NAPTR、DS 等记录，并对接 Vercel、Netlify 等平台的根域名验证。

注册域名

  1. 注册账号并同意服务条款
  2. 提交子域名申请，填写用途说明
  3. 等待管理员审核（通常很快）
  4. 通过后自行添加所需 DNS 记录

创建子域名时不会写入任何 DNS 记录。

产品服务

  • 免费二级域名根域名下自由申请
  • 多类型解析覆盖 10 余种主流记录
  • 根域名验证Vercel / Netlify / DNSPod
  • Cloudflare 加持全球 Anycast 解析
